# 给 Codex 的小夏项目交付说明 v1.3

更新：2026-11-04。本说明与项目合同 v1.3 优先解释前序研究中的实现建议。

## 交付与质量要求

项目交付目标、真实结果和已约定验收不变。论文、模型、算法、框架、目录与服务拆分、内部表示和实验组织可以自主改进、组合、替换或放弃。偏离论文无需另行请示；改变产品目标或验收口径由 Owner 裁决。

v1.3 新增工程质量章节，完整并入主合同；单独工程册是从同一源文生成的便于阅读版本。规则编号相同，不存在两套标准。规模阈值是项目默认检查线，超线需要结构审查、修正或有证据的局部例外；文件越短、测试越多、模块越多均不自动意味着质量更好。

小夏必须保留持续认知、自然交流、阅读与主动性、完整歌曲与戏曲、共同办事、跨渠道与恢复能力。认知推理与规划允许强模型发挥；数据、权限、状态和交付边界由可信运行时维护。既定授权范围内的动作沿用有效授权，不新增逐次确认流程。

## 本版新增

- 代码质量：类型、显式状态、错误语义、取消与提交竞态、资源清理、维护性与反例。
- 文件质量：源码、测试、配置、文档、上游代码、vendor、生成物、模型、媒体、日志、缓存和发行件分类管理。
- 结构与架构：按变化原因划分职责、依赖方向、状态权威、注册与能力、全局模型补丁、真实变更影响。
- 验证与治理：25 维矩阵、Q01-Q15、G1/G2/G3、局部例外与存量基线、PR 完成判据、迁移恢复、供应链、发布证据。
- 仓库衔接：R01-R06 静态输入和 EQ1-EQ4 落地任务；当前快照仍为 8c63aff5a18fcccd624ad0f29ee70f303e15975b。

## 建议阅读顺序

1. `contract/Xiaoxia_Project_Contract_v1.3.md`：完整合同，原产品内容与新工程章都在。
2. `architecture/Xiaoxia_Architecture_v1.3.pdf`：三页，项目总图、演唱与基座、工程依赖／状态／质量门。
3. `engineering/Xiaoxia_Engineering_Standards_v1.3.md`：工程章独立阅读；按规则编号定位。
4. `engineering/quality_policy.example.json`：质量政策模板；先按 EQ1 校准路径、工具、基线，再实施检查。它不是当前已安装的 CI 配置。
5. 两份质量 CSV 与规则 JSON：检索 25 维映射、15 个验收场景和条款编号，便于拆任务与核对遗漏。
6. 相关专项研究与原文索引：按当前问题阅读，采用有用机制，允许发现更好的替代路线。
